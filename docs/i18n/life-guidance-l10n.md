# Life Guidance preview: localization status

Strings live in `src/lib/i18n/lifeGuidance/{en,fr,ar,ur}.ts`, one file per locale, in the same layout as `src/lib/i18n/`.
Each locale file is typed against `en.ts`. `locales.test.ts` checks that every key, including each reference text, exists and is
non-empty in en, fr, ar and ur. It also checks that ar and ur are in Arabic script, that no forbidden wording appears, and that no
locale is marked reviewed. Urdu is RTL, like Arabic. The drawer sets `dir` and `lang` from the UI language and opts out of the DOM
catalog (`data-no-ar`), because its text is already native.

**Status: EN is the reference. FR, AR and UR are machine-written DRAFTS for the Language Reviewer. None of them is reviewed.**
The FR and AR UI labels had an AI-assisted advisory check on 4 Nov 2026. That check is not a sign-off.
The Urdu element and zodiac names come from the existing catalog, `public/i18n/ur-ui.json`.
Arabic mansion names, Lisān roots and Ibn Qutayba's headings are kept verbatim, as verified, in every language.
Qur'an text is never stored here: it is fetched from the bundled Tanzil text.

To change wording later, edit only the locale file. No component changes are needed.
